Split window Shortcut in Excel

Use this quick reference to learn the Windows shortcut, Mac shortcut, Ribbon path, and best use case for split window in Excel.

Shortcut keys

WindowsAlt → W → S
MacNo direct shortcut

Ribbon path

View → Split

What it does

Splits the worksheet into multiple panes that can be scrolled independently. Great for comparing different parts of a large sheet.

How to use this shortcut

  1. Open the Excel workbook and select the relevant cell, row, column, range, or sheet.
  2. Press the shortcut keys shown above for your platform.
  3. Confirm any dialog options if Excel opens a menu or prompt.

FAQ

What is the Excel shortcut for split window?

On Windows, use Alt → W → S. On Mac, use No direct shortcut.

Where is split window in the Excel Ribbon?

The Ribbon path is View → Split.
